# Codex Project Instructions

This repository implements Rowel Sabahat's personal portfolio. Read docs/DESIGN_BRIEF.md and docs/IMPLEMENTATION_PLAN.md before changing code. The latest approved mockup is the visual reference, but the explicit written decisions override ambiguities in the image.

- Build a single vertically scrolling, editorial 1980s retro-tech portfolio, not a generic tech dashboard.
- Avoid Japanese lettering, purple synthwave tropes, heavy repeated UI cards, and excessive/glitchy animations.
- The hero portrait may not overlap or obscure text. Do not assume the reference portrait is the actual user.
- Keep Education deliberately calm and typographic; the experience carousel and map can be more visually expressive.
- Reimagined employer identity assets must remain clearly identifiable, and never be presented as official logos.
- Use real geo data, country outlines only, and accurately placed city markers. Highlight a large city-logo/story panel upon interaction.
- Never fabricate dates, personal claims, job details, project metrics, residence durations, or external profile links. Use explicit TODO placeholders.
- Preserve accessibility: keyboard operation, focus states, mobile/touch equivalents, alt text, and reduced-motion accommodations.
- Implement one approved phase at a time. Before editing, summarize the specific phase's scope. After editing, run relevant checks and explain what was actually validated.
- For substantive UI changes, view the result in a browser and capture desktop/mobile screenshots when the environment supports it. If browser tools are unavailable, say so and give the user manual preview steps.
- Do not deploy publicly or install large unneeded dependencies without explaining the reason and obtaining approval where appropriate.
